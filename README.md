# Swift Agent Skills Bundle

A single repo bundling the community agent skills listed in [twostraws/Swift-Agent-Skills](https://github.com/twostraws/Swift-Agent-Skills), laid out like [Dimillian/Skills](https://github.com/Dimillian/Skills): one self-contained folder per skill at the repo root, each with a `SKILL.md`.

Every folder (and the `name:` in its `SKILL.md`) is prefixed with the author's name, e.g. `paul-hudson-swiftui-pro`, so skills with similar names stay distinguishable.

Intentionally **not** included: Thomas Ricouard's (Dimillian) skills and Rudrank Riyam's App Store Connect (`asc-*`) skills — both are installed separately.

## Usage

Each skill is self-contained: copy the folder(s) you want into your project's skills directory (for example `.claude/skills/`, `.agents/skills/`, or wherever Bitrig expects them). See each `SKILL.md` for triggers and references.

Symlinks from the upstream repos were resolved into real files and plugin-packaging duplicates were dropped, so every skill is a plain folder.
